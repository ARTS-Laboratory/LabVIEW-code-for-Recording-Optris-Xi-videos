# LabVIEW-code-for-Recording-Optris-Xi-videos
LabVIEW code to operate Optris thermal cameras.

The software development kit (SDK) must be installed for the code to function. The installer can be found [here](SDK). 

Implementation of camera preview footage in LabVIEW is in progress. There is no preview.
